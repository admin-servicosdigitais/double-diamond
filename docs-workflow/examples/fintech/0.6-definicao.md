# PRD — Antecipação de Recebíveis Integrada

**Referência**: OPP-20260409-001 | **Versão**: 1.0 | **Data**: 2026-04-09
**PM**: [PM Name] | **Tech Lead**: [TL Name]

## Contexto e motivação
61% das PMEs elegíveis já antecipam via banco com processo de 2-5 dias e taxa de 2.5-4% a.m. Validação com 8 usuários confirmou demanda por antecipação integrada com aprovação instantânea.

## Objetivos e métricas
| Objetivo | Métrica | Baseline | Meta |
|----------|---------|----------|------|
| Ativação | % elegíveis que antecipam 1x | 0% | 10% em 90d |
| Retenção | Retenção do segmento PME | 82% | 94% em 180d |
| Receita | Spread mensal | R$ 0 | R$ 100k em 180d |

## Requisitos funcionais
| ID | Requisito | Prioridade | Critério de aceitação |
|----|-----------|------------|----------------------|
| RF-01 | Widget de valor disponível no dashboard | Must | Dado PME elegível, quando acessa dashboard, então vê valor disponível atualizado |
| RF-02 | Simulação de antecipação | Must | Dado valor selecionado, quando simula, então vê taxa, IOF, valor líquido e prazo |
| RF-03 | Confirmação e execução | Must | Dado simulação aceita, quando confirma, então antecipação é processada em < 30s |
| RF-04 | Extrato de antecipações | Must | Dado antecipação realizada, quando acessa extrato, então vê histórico completo |
| RF-05 | Cálculo de elegibilidade | Must | Dado dados transacionais, quando scoring roda, então determina limite e taxa |
| RF-06 | Explicação de custos em reais | Should | Dado simulação, quando vê custo, então valores em R$ (não só %) |

## Requisitos não-funcionais
| ID | Requisito | Especificação |
|----|-----------|--------------|
| RNF-01 | Performance | Scoring e aprovação p95 < 2s |
| RNF-02 | Disponibilidade | 99.9% (serviço crítico financeiro) |
| RNF-03 | Multi-tenancy | Isolamento por tenant_id; dados financeiros encriptados por tenant |
| RNF-04 | Segurança | Dados encriptados at rest (AES-256) e in transit (TLS 1.3); PCI-DSS para dados financeiros |
| RNF-05 | Auditoria | Toda operação logada com tenant_id, user_id, timestamp, valores |

## Fora de escopo
- Crédito pessoal ou sem colateral
- Antecipação recorrente automática (fase 2)
- Gestão de cobrança de inadimplência (parceiro)

## Release strategy
- **Fase 1 (MVP)**: RF-01 a RF-06, 50 clientes piloto, feature flag
- **Fase 2**: antecipação recorrente, dashboard de analytics para PME
- **Feature flags**: `anticipation_enabled`, `anticipation_auto_recurring`
