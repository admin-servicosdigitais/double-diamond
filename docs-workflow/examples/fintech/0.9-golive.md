# Playbook de Suporte — Antecipação de Recebíveis

## Problemas esperados
| Sintoma | Causa provável | Ação | Escalação |
|---------|---------------|------|-----------|
| "Não vejo opção de antecipar" | Não elegível ou flag desativada | Verificar elegibilidade no admin | Se elegível e sem widget → eng P2 |
| "Antecipação travou em processando" | Callback do parceiro não chegou | Verificar status no painel do parceiro | Se > 30min → eng P1 |
| "Valor disponível está errado" | Cache stale ou transação recente | Aguardar 15min (cache TTL) | Se persistir → eng P2 |
| "Quero cancelar antecipação" | Arrependimento | Não é possível cancelar após aprovação; informar | Reclamação → CS |

## Critérios de escalação
| Sev | Critério | Para quem | SLA |
|-----|---------|-----------|-----|
| P1 | Operação financeira incorreta / dados vazados | Eng on-call + security | 15min |
| P2 | Feature não funciona para elegível | Eng team | 2h |
| P3 | Dúvida ou sugestão | Backlog | Próximo sprint |
