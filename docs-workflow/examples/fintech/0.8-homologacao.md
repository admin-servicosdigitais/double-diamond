# Release Notes — Antecipação de Recebíveis v1.0.0

**Data prevista**: 2026-05-15 | **Tipo**: Feature

## O que muda para o usuário
- Widget "Antecipe seus recebíveis" no dashboard para PMEs elegíveis
- Simulação de antecipação com valor, taxa, IOF e valor líquido em tempo real
- Aprovação instantânea e depósito em até 1h
- Extrato de antecipações no histórico financeiro

## O que muda internamente
- Novo serviço `anticipation-service` com integração ao parceiro financeiro
- Scoring engine baseado em dados transacionais
- Pipeline de auditoria para operações financeiras

## Breaking changes
- Nenhum

## Feature flags
| Flag | Estado | Rollout |
|------|--------|---------|
| anticipation_enabled | OFF | Ativação manual para 50 pilotos |

# Plano de Rollout — Antecipação de Recebíveis

## Sequência
| Etapa | Ambiente | Ação | Critério de avanço | Resp |
|-------|---------|------|-------------------|------|
| 1 | Staging | Deploy + teste integrado com sandbox do parceiro | Testes passam, operação simulada OK | DevOps |
| 2 | Prod (flag OFF) | Deploy do serviço | Health checks OK | DevOps |
| 3 | Prod (10 pilotos) | Ativar flag para 10 PMEs | 0 erros em 48h, 3+ simulações | PM + SRE |
| 4 | Prod (50 pilotos) | Expandir | Error rate < 0.1%, feedback positivo | PM + SRE |
| 5 | Prod (todos elegíveis) | GA | Métricas estáveis 7 dias | PM |

## Critérios de rollback
1. Error rate > 1% em operações financeiras
2. Qualquer vazamento de dados entre tenants
3. Parceiro financeiro indisponível > 30min sem fallback

# Checklist UAT — Antecipação de Recebíveis

- [ ] Audit log completo para cada operação
- [ ] Isolamento entre tenants validado
