# Decisão de Continuidade — Antecipação de Recebíveis

## Recomendação: **Iterar**

## Justificativa
Ativação superou a meta (13.2% vs 10%), inadimplência controlada (1.8%), mas receita ficou 22% abaixo da meta. Análise mostra que ticket médio de antecipação é menor que o projetado (clientes testando com valores pequenos).

## Ajustes priorizados
1. Incentivo para primeira antecipação com valor maior (taxa promocional para > R$ 10k)
2. Expandir para boletos (15 tickets pedindo)
3. Corrigir arredondamento do IOF

## Lições aprendidas
1. **Funcionou**: UX simples e aprovação instantânea foram o diferencial (não a taxa)
2. **Não funcionou**: projeção de receita assumiu ticket médio alto desde o início
3. **Faremos diferente**: próximas features financeiras terão período de "warmup" no forecast
