# Ficha da Oportunidade — Trilhas de Aprendizado Adaptativas

**ID**: OPP-20260409-002
**Data**: 2026-04-09
**Fonte**: Análise de dados — 68% dos usuários abandonam cursos após módulo 3
**Tipo**: Dor do cliente
**Sponsor provisório**: Head de Produto
**Status**: Aceita para discovery

## Descrição da demanda
Gestores de RH reportam que colaboradores iniciam treinamentos obrigatórios mas não completam. Dados de analytics confirmam: taxa de conclusão é 32%, com abandono concentrado entre módulos 3 e 4. Hipótese interna é que o conteúdo é genérico demais para diferentes níveis de conhecimento.

## Segmento / Persona afetada
Colaboradores de empresas mid-market (200-2000 funcionários) que precisam completar treinamentos de compliance, onboarding e upskilling técnico. Secundariamente, gestores de RH que precisam reportar conclusão.

## Impacto estimado
- Alcance: ~85.000 learners ativos em 340 contas enterprise
- Frequência: diário — cada learner deveria acessar conteúdo 3x/semana
- Severidade: alta — clientes ameaçam cancelar por baixo ROI percebido
- Valor de negócio: redução de churn enterprise estimada em R$ 800k ARR retido + upsell de módulo premium

## Demandas similares conhecidas
- Churn interview Q4/2025: 3 de 5 ex-clientes citaram "conteúdo genérico"
- Feature request #187: "Quero personalizar trilha por cargo"
- RFP perdida: cliente pediu trilha adaptativa e escolheu concorrente

## Decisão
Aceita para discovery. Justificativa: problema com dados claros (68% de abandono), impacto direto em retenção de contas enterprise e diferenciador competitivo em RFPs.

# Hipótese Inicial — Trilhas Adaptativas

**Referência**: OPP-20260409-002

## Hipótese
Acreditamos que trilhas de aprendizado que se adaptam ao nível de conhecimento prévio do colaborador vão aumentar a taxa de conclusão de 32% para 55% porque o abandono ocorre quando o conteúdo é fácil demais (tédio) ou difícil demais (frustração) para o nível do learner.

## O que precisa ser verdade
1. O abandono é causado por inadequação de nível (não por falta de tempo ou motivação)
2. Conseguimos inferir o nível do learner com um assessment inicial rápido (< 5min)
3. Temos conteúdo suficiente em diferentes níveis para montar trilhas variadas
4. Gestores de RH aceitam trilhas diferentes para o mesmo treinamento obrigatório

## Como saberemos que funciona
- Métrica primária: taxa de conclusão de trilha
- Meta: de 32% para 55%
- Prazo de validação: 60 dias com grupo piloto de 3 contas

## Riscos conhecidos
- Risco de conteúdo: pode não ter material suficiente em 3 níveis para todas as trilhas
- Risco de compliance: RH pode exigir que todos passem pelo mesmo conteúdo por questões legais
