## Problemas esperados
| Sintoma | Causa provável | Ação | Escalação |
|---------|---------------|------|-----------|
| "Assessment não carrega" | Serviço fora ou rede | Verificar status do assessment-engine | Se down → eng P1 |
| "Fui classificado errado" | Assessment impreciso | Orientar a refazer (1x permitido) | Se padrão → PM revisar questões |
| "Não consigo acessar módulo pulado" | Bug no "Revisar" | Testar no admin | Se confirmar → eng P2 |
| "Gestor quer relatório consolidado" | Feature existe | Orientar caminho no painel de RH | Se não funciona → eng P2 |

# Comunicação — Trilhas Adaptativas

## In-app (para learner)
**Título**: Sua trilha agora é personalizada
**Corpo**: Faça um diagnóstico rápido de 5 minutos e receba uma trilha adaptada ao seu nível. Menos repetição, mais aprendizado.
**CTA**: Iniciar diagnóstico

## Email para gestores RH
**Assunto**: Novidade — trilhas adaptativas para sua equipe

Olá [nome],

Sabemos que engajamento em treinamentos é um desafio. Por isso, agora suas trilhas se adaptam ao nível de cada colaborador.

Como funciona: diagnóstico de 5min → trilha personalizada → quiz final unificado. O relatório mostra conclusão por nível, mantendo a comparabilidade.

Está disponível para as 5 trilhas mais usadas. Quer ativar para sua equipe?

## Notas para CS
- **Pitch**: "A taxa de conclusão vai subir porque o conteúdo agora respeita o nível de cada pessoa"
- **Objeção "todos precisam ver o mesmo conteúdo"**: quiz final é unificado; avalia o mesmo outcome independente do caminho
