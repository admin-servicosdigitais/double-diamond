# Alternativas de Solução — Trilhas Adaptativas

**Referência**: OPP-20260409-002

## Alternativa A: Assessment + ramificação manual
- **Abordagem**: quiz inicial classifica em 3 níveis; content team mapeia manualmente módulos por nível
- **Esforço**: P (3-4 semanas) — lógica simples, trabalho operacional no conteúdo
- **Risco principal**: escala — cada nova trilha exige mapeamento manual
- **Impacto esperado**: resolve o problema para trilhas existentes rapidamente

## Alternativa B: Motor adaptativo com IA
- **Abordagem**: modelo de ML que analisa comportamento do learner em tempo real e ajusta dificuldade dinamicamente
- **Esforço**: G (4-5 meses) — desenvolvimento de modelo, dados de treino, infraestrutura
- **Risco principal**: precisa de volume de dados que talvez não temos
- **Impacto esperado**: experiência altamente personalizada, escala automática

## Alternativa C: Repetição espaçada + skip logic
- **Abordagem**: learner pode pular módulos provando competência via quiz; conteúdo que errar volta em intervalos crescentes
- **Esforço**: M (6-8 semanas) — quiz engine + algoritmo de espaçamento
- **Risco principal**: learner pode pular conteúdo importante se quiz for superficial
- **Impacto esperado**: respeita quem já sabe, reforça quem não sabe

# Conceito Escolhido — Assessment + Ramificação Manual (fase 1)

**Alternativa selecionada**: A — com evolução para C na fase 2

## Descrição do conceito
Antes de iniciar qualquer trilha, learner faz assessment de 5 minutos (10-15 questões). Resultado classifica em Iniciante, Intermediário ou Avançado. Trilha se reorganiza: iniciante vê tudo; intermediário pula fundamentos; avançado vai direto para aplicação prática.

## Jornada proposta
1. RH atribui trilha → 2. Learner recebe notificação → 3. Inicia assessment (5min) → 4. Recebe classificação com feedback → 5. Trilha adaptada carrega → 6. Progride nos módulos do seu nível → 7. Quiz final unificado para todos os níveis → 8. Certificado gerado

## Trade-offs aceitos
| Ganhamos | Abrimos mão | Por que é aceitável |
|----------|-------------|-------------------|
| Lançamento em 4 semanas | Adaptação em tempo real | Assessment inicial resolve 80% do problema |
| Simplicidade técnica | Personalização granular | 3 níveis cobrem a maioria dos casos |
| Controle do content team | Escala automática | Temos 12 trilhas prioritárias; fazemos manual |

## Riscos
| Risco | Prob | Impacto | Mitigação |
|-------|------|---------|-----------|
| Assessment impreciso | Média | Alto | Opção de trocar de nível manualmente |
| Content team sobrecarregado | Média | Médio | Priorizar 5 trilhas mais usadas no MVP |
| RH resistir a trilhas diferentes | Baixa | Alto | Quiz final unificado garante comparabilidade |
