# PRD — Trilhas de Aprendizado Adaptativas

**Referência**: OPP-20260409-002 | **Versão**: 1.0 | **Data**: 2026-04-09
**PM**: [PM Name] | **Tech Lead**: [TL Name]

## Contexto e motivação
Taxa de conclusão de 32% com abandono concentrado no módulo 3. Correlação r=0.71 entre experiência prévia e conclusão. Validação confirmou que assessment + trilha adaptada é bem aceito (90% completam assessment, valor emocional de "respeitar meu tempo").

## Objetivos e métricas
| Objetivo | Métrica | Baseline | Meta |
|----------|---------|----------|------|
| Engajamento | Taxa de conclusão | 32% | 55% em 60d |
| Retenção | Retenção enterprise (piloto) | 78% | 90% em 180d |
| Qualidade | Score pós-trilha | 62/100 | 78/100 em 90d |

## Requisitos funcionais
| ID | Requisito | Prioridade | Critério de aceitação |
|----|-----------|------------|----------------------|
| RF-01 | Assessment inicial (10-15 questões, 5min) | Must | Dado learner, quando inicia trilha, então assessment carrega em < 2s com timer |
| RF-02 | Classificação automática em 3 níveis | Must | Dado respostas, quando assessment completo, então classifica Iniciante/Inter/Avançado |
| RF-03 | Trilha reorganizada por nível | Must | Dado nível, quando trilha carrega, então mostra módulos adequados com pulados em cinza |
| RF-04 | Acesso a módulos pulados ("Revisar") | Must | Dado módulo pulado, quando clica "Revisar", então abre conteúdo |
| RF-05 | Opção "Pular assessment" | Should | Dado learner, quando não quer quiz, então começa como Iniciante |
| RF-06 | Reporting unificado para RH | Must | Dado gestor RH, quando acessa relatório, então vê conclusão por nível com score equivalente |

## Requisitos não-funcionais
| ID | Requisito | Especificação |
|----|-----------|--------------|
| RNF-01 | Performance | Assessment load < 2s; classificação < 500ms |
| RNF-02 | Multi-tenancy | Conteúdo de nível configurável por tenant; dados de assessment isolados |
| RNF-03 | Acessibilidade | WCAG 2.1 AA para assessment e trilha |
| RNF-04 | Dados | Logs de assessment, classificação e progresso por learner para analytics |

## Fora de escopo
- Geração automática de conteúdo por IA
- Adaptação em tempo real durante a trilha (fase 2 com skip logic)
- Gamificação

## Release strategy
- **Fase 1 (MVP)**: Assessment + 3 níveis para 5 trilhas mais usadas, 3 contas piloto
- **Fase 2**: skip logic + repetição espaçada, expansão para todas as trilhas
- **Feature flags**: `adaptive_trails_enabled`, `assessment_skip_option`
