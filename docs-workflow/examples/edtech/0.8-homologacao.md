# Release Notes — Trilhas Adaptativas v1.0.0

**Data prevista**: 2026-05-01 | **Tipo**: Feature

## O que muda para o usuário
- Assessment de 5 minutos antes de iniciar trilha (10-15 questões)
- Classificação automática: Iniciante, Intermediário ou Avançado
- Trilha reorganizada pelo nível com módulos pulados acessíveis via "Revisar"
- Opção de pular assessment e começar como Iniciante
- Relatório para RH com conclusão por nível

## O que muda internamente
- Novo serviço `assessment-engine` com banco de questões por trilha
- Content map por nível para 5 trilhas prioritárias
- Tracking de progresso por nível no analytics pipeline

## Feature flags
| Flag | Estado | Rollout |
|------|--------|---------|
| adaptive_trails_enabled | OFF | 3 contas piloto |
| assessment_skip_option | ON | Global |

# Plano de Rollout — Trilhas Adaptativas

## Sequência
| Etapa | Ambiente | Ação | Critério | Resp |
|-------|---------|------|---------|------|
| 1 | Staging | Deploy + teste com trilha de compliance | Assessment funciona, trilha adapta | QA |
| 2 | Prod (flag OFF) | Deploy | Health OK | DevOps |
| 3 | Prod (1 conta piloto) | Ativar para 500 learners | Assessment completion > 80% | PM |
| 4 | Prod (3 contas) | Expandir | Engajamento módulo 3 > 60% | PM |
| 5 | Prod (todas contas) | GA para 5 trilhas | Conclusão > 45% | PM |

## Critérios de rollback
1. Assessment completion < 60% (indica UX quebrada)
2. Classificação > 80% no mesmo nível (assessment enviesado)
3. Regressão em taxa de conclusão vs grupo controle

# Checklist UAT — Trilhas Adaptativas

## Funcional
- [ ] Assessment carrega em < 2s
- [ ] Classificação correta (testado com respostas conhecidas)
- [ ] Trilha se reorganiza pelo nível
- [ ] Módulos pulados acessíveis via "Revisar"
- [ ] "Pular assessment" funciona
- [ ] Relatório RH mostra dados por nível

## Não-funcional
- [ ] 500 assessments simultâneos com p95 < 2s
- [ ] Dados de assessment isolados por tenant
- [ ] WCAG 2.1 AA validado no assessment

## Release readiness
- [ ] Conteúdo de 5 trilhas mapeado por nível
- [ ] Content team revisou classificação de módulos
- [ ] CS treinado para explicar assessment a gestores RH
- [ ] Rollback testado (flag OFF restaura trilha original)
